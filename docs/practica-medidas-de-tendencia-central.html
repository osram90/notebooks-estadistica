Medidas de tendencia central

Las medidas de tendencia central resume un conjunto de datos representándolos mediante un valor central.

  • Media: promedio de todos los valores.
    Se calcula sumando los datos y dividiendo entre la cantidad de elementos. Puede verse afectada por valores extremos.

  • Mediana: valor que queda en el centro al ordenar los datos. Si hay una cantidad par de valores, se calcula el promedio de los dos centrales.

  • Moda: valor que aparece con mayor frecuencia. Un conjunto puede tener varias modas o ninguna.

Fórmulas de las medidas de tendencia central

1. Media o promedio

Suma todos los valores y divídelos entre la cantidad total de datos:

[
\text{Media}=\frac{x_1+x_2+\cdots+x_n}{n}
=\frac{\sum_{i=1}^{n}x_i}{n}
]c

Ejemplo:

[
\text{Media}=\frac{4+2+7+5+3+5}{6}
=\frac{26}{6}\approx4.33
]

Fórmulas de las medidas de tendencia central

1. Media o promedio

Se obtiene sumando todos los valores y dividiendo el resultado entre la cantidad total de datos:

[
\text{Media}=\frac{x_1+x_2+\cdots+x_n}{n}
=\frac{\sum_{i=1}^{n}x_i}{n}
]

Ejemplo:

[
\text{Media}=\frac{4+2+7+5+3+5}{6}
=\frac{26}{6}\approx 4.33
]

media = sum(datos) / len(datos)

2. Mediana

Primero se ordenan los datos. La mediana es el valor central:

[
\text{Mediana}=
\begin{cases}
x_{\frac{n+1}{2}}, & \text{si } n \text{ es impar}\[4pt]
\frac{x_{\frac{n}{2}}+x_{\frac{n}{2}+1}}{2}, & \text{si } n \text{ es par}
\end{cases}
]

Ejemplo con los datos ordenados [2, 3, 4, 5, 5, 7]:

[
\text{Mediana}=\frac{4+5}{2}=4.5
]

ordenados = sorted(datos)
n = len(ordenados)

if n % 2 == 1:
    mediana = ordenados[n // 2]
else:
    mediana = (ordenados[n // 2 - 1] + ordenados[n // 2]) / 2
# 1️⃣ Definir los datos (puedes cambiar estos números)
datos = [4, 2, 7, 5, 3, 5]

# 2️⃣ Media (promedio)
media = sum(datos) / len(datos)

# 3️⃣ Mediana (valor central)
ordenados = sorted(datos)      # [2, 3, 4, 5, 5, 7]
n = len(ordenados)
if n % 2 == 1:                 # longitud impar
    mediana = ordenados[n // 2]
else:                          # longitud par
    mediana = (ordenados[n // 2 - 1] + ordenados[n // 2]) / 2

# 4️⃣ Moda (valor más frecuente)
from collections import Counter
frecuencias = Counter(datos)   # {4:1, 2:1, 7:1, 5:2, 3:1}
mayor_frecuencia = max(frecuencias.values())
modas = [
    valor
    for valor, cantidad in frecuencias.items()
    if cantidad == mayor_frecuencia
]

# 5️⃣ Mostrar los resultados
print("Datos:", datos)
print("Media:", media)
print("Mediana:", mediana)
print("Moda:", modas)

3. Moda

Es el valor o los valores que tienen la mayor frecuencia:

[
\text{Moda}=\operatorname{arg,max}_{x} f(x)
]

donde (f(x)) es la cantidad de veces que aparece (x).

En el ejemplo, el 5 aparece dos veces, por lo que es la moda:

from collections import Counter

frecuencias = Counter(datos)
mayor_frecuencia = max(frecuencias.values())

modas = [
valor
for valor, cantidad in frecuencias.items()
if cantidad == mayor_frecuencia
]

En general, la media se utiliza con datos simétricos, la mediana con datos que contienen valores extremos y la moda para identificar el valor más frecuente.

import numpy as np
import matplotlib.pyplot as plt

# Parámetros de la distribución normal
n = 10_000
media = 0
desviacion = 1

# Semilla para hacer reproducible la simulación
rng = np.random.default_rng(42)
datos = rng.normal(media, desviacion, n)

# Valores y densidad de la curva normal
x = np.linspace(media - 4 * desviacion, media + 4 * desviacion, 500)
curva_normal = (
    1 / (desviacion * np.sqrt(2 * np.pi))
    * np.exp(-0.5 * ((x - media) / desviacion) ** 2)
)

# Histograma y curva normal
plt.figure(figsize=(8, 5))
plt.hist(
    datos,
    bins=40,
    density=True,
    color="skyblue",
    edgecolor="white",
    alpha=0.8,
    label="Muestra simulada"
)
plt.plot(x, curva_normal, color="red", linewidth=2, label="Curva normal")
plt.title("Distribución normal simulada")
plt.xlabel("Valores")
plt.ylabel("Densidad")
plt.legend()
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()

print(f"Media simulada: {np.mean(datos):.4f}")
print(f"Desviación simulada: {np.std(datos):.4f}")
Media simulada: -0.0102
Desviación simulada: 1.0063

Aquí tienes un bloque de código compacto que dibuja la curva normal estándar y una línea vertical en el centro (donde está la media, x = 0). La línea se agrega automáticamente a la leyenda.

import numpy as np
import matplotlib.pyplot as plt

# Generar puntos para la curva normal estándar
x = np.linspace(-3, 3, 1000)
y = (1 / np.sqrt(2 * np.pi)) * np.exp(-0.5 * x**2)

# Dibujar la curva
plt.plot(x, y, label="Curva normal estándar")

# Línea vertical en el centro (media = 0)
plt.axvline(
    x=0,                     # ← línea en el centro
    color="#e63946",
    linestyle="--",
    linewidth=2,
    label="Media (centro) = 0"
)

# Mostrar leyenda y gráfico
plt.legend()
plt.show()
